# A16：300 µs 性能预算豁免到 1.1

- 日期：2026-10-28
- 状态：已接受（已于 2026-11-02 更新实测）
- 关联：[docs/07 §12.1](../07-roadmap-risks.md)、[docs/05 §11.1](../05-msys2-dev-environment.md)

## 背景

`docs/01` 的质量目标为 100 刚体单步 ≤ 300 µs。M1 实测（Release）为 9 058 µs，差距约 30×，主要成本在质量矩阵装配与稠密求解。

## 决策

1.1 之前不把 300 µs 作为发布阻塞项；性能工作以「分项计时 + 可复现基准」推进，达标后再撤销豁免。

## 后果

- 正面：允许先用 CRBA/积分器档位换取实际收益，不被单一指标阻塞功能。
- 负面：需要显式记录当前档位，避免把「性能档」当成默认行为对外宣称。

## 验证证据

| 日期 | 构建 | step_us | 说明 |
|---|---|---|---|
| 2026-10-28 | Release | 8 947 | 基线（CRBA 前） |
| 2026-11-02 | Release | 963 | CRBA 装配 7.6× |
| 2026-11-02 | Release | 216 | 半隐式档（可选，非默认） |

## 复审条件

任一条件满足即复审：默认档达标；或出现必须同时满足「RK4 精度 + 300 µs」的需求（届时启动 ABA）。
