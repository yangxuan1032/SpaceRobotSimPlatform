# 架构决策记录（ADR）

- 状态：v0.1（2026-11-02）

本目录存放**可独立引用的 ADR 条目**。索引与编号真源仍是 [docs/01 §8](../01-architecture.md) 的决策表；本目录用于给每条决策补「背景 / 决策 / 后果 / 验证证据」，避免把长篇理由挤在总表里。

## 约定

| 项 | 规则 |
|---|---|
| 文件 | `A<两位编号>-<kebab-slug>.md`，编号与 docs/01 决策表一致 |
| 头部 | 日期、状态（提议/已接受/已取代/已废弃）、关联文档 |
| 必填 | 背景、决策、后果（正面/负面）、验证证据、复审条件 |
| 取代 | 新增文件并在旧文件状态写「已取代 by Axx」，不删除历史 |
